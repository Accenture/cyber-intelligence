Linux_RustyRocket_Proxy

📅 11 March 2026 🏷 Accenture Security ATHENA (cw) 🔖 v1.0

Linux_RustyRocket_Proxy.yar detects the Linux x86-64 ELF variant of the RustyRocket proxy. It requires the elf YARA module and uses a combination of obfuscated string fragments, rustls error strings, and proxy-specific markers.

Known Hash

  • d92377d14dc2c3cd818fcf3a37343ec30a3495b9ba2eedaa2d41b698ee159b08 — proxy (ELF)

Rule

import "elf"

rule Linux_RustyRocket_Proxy
{
  meta:
    Author   = "Accenture Security ATHENA (cw)"
    Date     = "11 March 2026"
    Desc     = "Detects Linux variant of Rusty Rocket Proxy"
    Version  = "1.0"

  strings:
    // Obfuscated string fragments (obfstr crate — partial UTF-8 sequences)
    $obfstr_version = { 76 65 72 73 }   // "vers"
    $obfstr_about   = { 61 62 6F 75 }   // "abou"
    $obfstr_usage   = { 75 73 61 67 }   // "usag"

    // rustls certificate error strings
    $rustls_1 = "BadDer" ascii
    $rustls_2 = "CertExpired" ascii
    $rustls_3 = "UnknownIssuer" ascii
    $rustls_4 = "InvalidCertValidity" ascii

    // TLS cipher suite identifiers
    $tls_1 = "TLS13_AES_128_GCM_SHA256" ascii
    $tls_2 = "TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256" ascii

    // Proxy listener and address strings
    $proxy_1    = "could not resolve to any address" ascii
    $proxy_2    = "ConnectionRefused" ascii
    $proxy_443  = "0.0.0.0:443PROXY"
    $proxy_ADDRS= "GproxyaddrsADDRS"

    // Agent config string (presence → NOT a proxy)
    $filter = "cidrsaddrsdomainssubdomainechstruct"

  condition:
    uint32(0) == 0x464C457F              // ELF magic
    and elf.machine == elf.EM_X86_64
    and filesize > 2MB
    and 2 of ($obfstr_*)               // At least 2 obfstr constants
    and 3 of ($rustls_*)               // rustls indicators
    and all of ($tls_*)
    and all of ($proxy_*)
    and not $filter
}

Rule Notes

  • Requires the elf YARA module — ensure your scanner supports it (yara-python >= 3.x, YARA >= 3.4).
  • The filesize > 2MB constraint eliminates small stub binaries; the statically-linked Rust proxy is substantially larger.
  • The $filter exclusion prevents matching the agent binary, which shares some proxy strings in a combined build.
  • Obfstr fragments target the obfstr compile-time string obfuscation crate — only partial sequences need to match.
