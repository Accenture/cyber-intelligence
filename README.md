Cyber Threat Intelligence — IOCs & Detection Rules

This site publishes Indicators of Compromise (IOCs), detection rules, and network fingerprints for cyber threat activity discovered through Accenture Cyber Intelligence research.

Content includes sample hashes, YARA detection rules for Windows and Linux, network-layer TLS fingerprints, and mitigation guidance to support defenders in detecting and responding to active threats.

What's Published Here
Sample Hashes — SHA-256 hashes for known malicious binaries across Windows and Linux platforms
YARA Rules — Detection rules targeting file, memory, and binary indicators
Network Fingerprints — JA4 and JA3 TLS fingerprints and protocol-level indicators for network-layer detection
Mitigation Guidance — Actionable recommendations for detection and response
