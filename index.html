Using this intelligence

Indicators

Add the sample hashes to EDR blocklists and SIEM watchlists, and search historical endpoint telemetry for earlier executions.

Network fingerprints

Alert on the JA4 and JA3 fingerprints in your NDR or SIEM pipeline, and prefer JA4 where your tooling supports it. Other software built on the same TLS library can share a fingerprint, so check destination, SNI and host context before blocking.

YARA rules

Copy a rule from its report page, save it as a .yar file and run it with the YARA command-line tool. You can also load it into any EDR, sandbox or file-scanning pipeline that accepts YARA rules.

# Scan a directory recursively and print the matching strings
yara -r -s rule.yar /path/to/scan

# Scan the memory of a running process (usually needs administrator or root rights)
yara -s rule.yar <PID>

Some rules import YARA modules such as pe or elf, which are included in standard YARA builds.

Mitigation guidance

Each report ends with recommendations specific to the threat. Use them to prioritise hardening and monitoring work.

Test before you block

Run new rules in alert-only mode first to measure false positives in your environment.

Sharing and feedback

Traffic Light Protocol

All content on this site is marked TLP:CLEAR under FIRST TLP 2.0. Recipients may share it without restriction, subject to standard copyright rules.

You are welcome to load the indicators and rules into your own tools and to redistribute them. Please credit Accenture Security APEX Labs. Keep the rule metadata (author, date, version) intact so others can trace updates.

Feedback

If a rule produces false positives, misses a sample it should catch, or a report contains an error, please open an issue on GitHub. Include the report and rule name, the rule version, your YARA version, and the SHA-256 of any file involved.

Do not attach malware samples to issues, and do not post client, personal or other sensitive data.

Disclaimer
