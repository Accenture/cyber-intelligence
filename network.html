Windows_RocketLaunch

📅 9 March 2026 🏷 Accenture ATHENA (JK / CW)

Windows_RustyRocket_Service_Launcher.yar detects RocketLaunch — the tool used to install and launch RustyRocket as a Windows service before exiting. It is distinct from the agent itself: it calls StartServiceCtrlDispatcherW but does not implement the service control handler callbacks, making it identifiable by absence.

Known Hashes

  • c2bc8ad1fa0dedb763e85a52c390462dfbccf6594b88664e33c672a9fb8b7a16 — svcrun.exe

Rule Notes

  • The key detection logic is the absence of service control handler strings ($NotFound*). A legitimate Windows service must register a handler; RocketLaunch calls the dispatcher but immediately exits, so these strings are absent.
  • The $Rust string (rust_panic) confirms this is a Rust-compiled binary, distinguishing it from other minimal service launchers.
  • The opcode sequence targets the core service dispatch loop with jump-table interleaving ([-] indicates byte-range wildcards between blocks).
