Windows_RustyRocket_Proxy

📅 13 March 2026 🏷 Accenture Security ATHENA (jk, cw)

Windows_RustyRocket_Proxy.yar detects Windows x86-64 PE binaries that implement the RustyRocket proxy component. It combines opcode-level patterns with proxy-specific error strings found in the Rust runtime.

Known Hashes

  • 886D107074F61D203AD15719DE37CD2582DA4CF47998B456A1CED71E9F1AE98A — proxy.exe
  • 6acd457f18bc2f1e190e5a7a7189aec61ed93927ea174ac7e00aeba6b521d8a9 — proxy.exe
  • 2011d47bcd639ccc3b2a887aa3bba95ed5288f09b7e0f0bce2358938968d3478 — ku8w13gi.exe

Rule

rule Windows_RustyRocket_Proxy
{
  meta:
    description = "Detects Windows versions of Rusty Rocket proxy"
    author      = "Accenture Security ATHENA (jk, cw)"
    date        = "2026-03-13"

  strings:
    // Division-based opaque predicate
    $div_pred = {
      8B 05 ?? ?? ?? ??   // mov eax, dword [rip+pool_A]
      31 D2               // xor edx, edx
      F7 35 ?? ?? ?? ??   // div dword [rip+pool_B]
    }

    // Paired memory read pattern
    $paired_read = {
      8B 05 ?? ?? ?? ??                              // mov eax, [rip+pool_A]
      ( 33 | 2B | 03 | 23 | 0B ) 05 ?? ?? ?? ??  // xor/sub/add/and/or eax,[rip+pool_B]
    }

    // Proxy error strings from Rust TLS runtime
    $proxy_handshake_eof     = "tls handshake eof" ascii
    $proxy_unexpected_poll   = "unexpected polling after handshake" ascii
    $proxy_join_cancel       = "JoinError::Cancelled(" ascii
    $proxy_task_cancel       = "task was cancelled" ascii

    // C2 server strings (presence → NOT a proxy, is a C2 agent)
    $c2_axum         = "_axum_fallback" ascii
    $c2_config_struct= "access_tokengatewaysstruct Config" ascii
    $c2_invalid_route= "Invalid route " ascii

  condition:
    uint16(0) == 0x5A4D
    and uint32(uint32(0x3C)) == 0x00004550   // PE signature
    and uint16(uint32(0x3C) + 4) == 0x8664   // AMD64
    and #div_pred > 30
    and #paired_read > 100
    and $proxy_handshake_eof
    and $proxy_unexpected_poll
    and $proxy_join_cancel
    and $proxy_task_cancel
    and not $c2_axum
    and not $c2_config_struct
    and not $c2_invalid_route
}

Rule Notes

  • High instance-count thresholds (#div_pred > 30, #paired_read > 100) reduce false positives — legitimate Rust binaries rarely hit these counts.
  • The C2 exclusion strings ensure the rule fires only on the proxy component, not the agent binary which shares some Rust runtime strings.
  • All four Rust TLS error strings must be present simultaneously; each alone is insufficient.
